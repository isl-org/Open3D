.. _dev_wheels:

Development wheels
##################

Development wheels for Open3D (``HEAD`` of ``main`` branch).

Use the following command to install the latest development version:

.. code-block:: bash

    pip install -U -f https://www.open3d.org/docs/latest/dev_wheels.html open3d
